บทที่ 1: ทำให้ได้ 1000 คะแนนเพื่อไปบทต่อไป

คำที่คุณสร้างจะแสดงที่นี่ พร้อมเพศของคำนาม (der/die/das) และคำแปลตามภาษาที่เลือก
    วิธีเล่น
    • เลือกตัวอักษรที่อยู่ติดกัน (รวมแนวทแยง) อย่างน้อย 3 ตัว ให้เป็นคำภาษาเยอรมัน แล้วกด ส่งคำ หรือลากแล้วปล่อยนิ้ว
    • คำยาวได้คะแนนคูณเพิ่ม ตัวอักษรหายาก (Ä Ö Ü J Q X Y) มีค่าสูง ป้าย CH นับเป็นสองตัวอักษร
    • ใช้ ss แทน ß เช่น STRASSE, FUSS
    • คำ 5–6 ตัวจะได้ป้าย ×2 สีแดงชาด คำ 7 ตัวขึ้นไปได้ป้าย ×3 แผ่นทอง ใช้ในคำถัดไปเพื่อคูณคะแนน
    • ระวัง หยดหมึก ตัวเลขบนป้ายจะนับถอยหลังทุกตา ถ้าถึง 0 คุณเสียขนนก 1 อัน ใช้ป้ายนั้นในคำเพื่อกำจัดและได้โบนัส
    • การสลับตัวอักษรนับเป็นหนึ่งตา ผ่านบทแล้วได้ขนนกคืน 1 อันและคำใบ้ครบ 3 ครั้ง
